# لباب الدار (Lbab El Dar) - تطبيق أندرويد

تطبيق أندرويد متكامل مبني باستخدام **Kotlin** و **Jetpack Compose** ومصمم بأحدث معايير **Material Design 3**.
تمت إعادة كتابة التطبيق مع الحفاظ على كافة الميزات والمنطق التجاري من تطبيق الويب الأصلي.

## أبرز الميزات المطبقة (Core Features)

1. **تجربة متعددة الأدوار (Multi-Persona Architecture):**
   - **الزبون (Customer):**
     - استعراض التصنيفات (مطاعم، بقالة، مخابز، حلويات، خضر وفواكه، قصابة، صيدليات).
     - استعراض المتاجر الجزائرية المميزة (مطعم القصبة العتيقة، مخبزة النخيل، طواجن الباهية وهران).
     - تفاصيل المتجر وإضافة المنتجات إلى السلة مع تحديد الكميات والأسعار بالدينار الجزائري (DZD).
     - سلة مشتريات تفاعلية، حساب تكلفة التوصيل بحسب الولاية، واختيار طريقة الدفع (عند الاستلام أو البطاقة الذهبية / CIB).
     - تتبع الطلبات مع شريط التقدم الزمني، ورمز التحقق السري للتسليم (OTP) المكون من 4 أرقام.
     - تقييم الطلبات والخدمة بنظام النجوم (1-5 نجوم) والتعليقات.
     - قائمة المفضلة للمتاجر والأطباق.
     - الملف الشخصي والعناوين المحفوظة وإدارة الاشتراكات المميزة (Slick-Pay & SATIM).
   - **التاجر (Merchant):**
     - لوحة تحكم التاجر مع إمكانية فتح وإغلاق المتجر.
     - إدارة طابور الطلبات الواردة (قبول الطلب -> بدء التحضير -> جاهز للاستلام).
     - إدارة قائمة المنتجات وتعديل توفرها.
     - المحفظة المالية للتاجر: عرض الرصيد المالي المتاح، وتقديم طلبات السحب (بريدي موب / CCP أو نقداً عبر الفروع).
   - **عامل التوصيل (Courier):**
     - زر التوفر للتوصيل (متصل / غير متصل).
     - لوحة استقبال وتتبع مهام التوصيل مع تفاصيل نقطة الاستلام ونقطة التسليم.
     - سير عمل تسليم تفاعلي متدرج، مع نافذة إدخال رمز التحقق (OTP) من الزبون لإتمام التسليم وضمان الأمان.
     - محفظة التوصيل: الأرباح المحققة والمبالغ النقدية المحصلة (Cash on Delivery).
   - **إدارة المنصة (Admin):**
     - إحصائيات عامة (حجم الطلبات، المتاجر المعتمدة، فروع السحب).
     - مراقبة كافة طلبات التوصيل في الجزائر.
     - مراجعة واعتماد أو رفض طلبات سحب الأرباح للتجار وعمال التوصيل.
     - إدارة فروع استلام الأموال النقدية عبر ولايات الوطن.

2. **الواجهة والهوية البصرية:**
   - تصميم عربي أصيل يدعم اتجاه الكتابة من اليمين إلى اليسار (RTL).
   - ألوان مادية حديثة مستوحاة من الهوية الجزائرية (البرتقالي الدافئ `#FF6600`، الكحلي الأنيق `#0F172A`، الأخضر الزمردي `#10B981`).
   - أيقونة تطبيق متكيفة (Adaptive Launcher Icon) مع طبقات foreground و background وجميع أحجام mipmap.

3. **البنية البرمجية (Architecture):**
   - بنية MVVM نظيفة مع `StateFlow` و `MutableStateFlow` لإدارة الحالة التفاعلية.
   - دعم التدوير والتكيف مع مختلف أحجام الشاشات.
   - دعم كامل لنظام Gradle Kotlin DSL مع كتالوج الإصدارات `libs.versions.toml`.
